# 📹 ESP32-S3 CAM Streamer
## IP-камера на ESP32-S3 N16R8 с веб-сервером

Прошивка для ESP32-S3 N16R8 с камерой OV2640. Поднимает веб-сервер на порту 80 и отдаёт MJPEG-поток в браузер. Подходит для домашнего видеонаблюдения, интеграции в Home Assistant или просто как локальная IP-камера без облаков.

## 📸 Что умеет
- 🎥 **MJPEG-поток** — в браузере по адресу `http://<ip_esp32>/`
- 📐 **Разрешение VGA (640×480)** — плавный FPS без задержек
- 📶 **Wi-Fi** — подключение к домашней сети
- 🔌 **Веб-сервер** — на базе `esp_http_server` (встроенный в ESP-IDF)
- 🏠 **Не требует интернета** — всё работает в локальной сети

## 🔌 Железо
| Что | Характеристики | Зачем |
|-----|----------------|-------|
| **ESP32-S3 N16R8** | 16MB Flash, 8MB PSRAM, WiFi/BLE | Микроконтроллер с PSRAM (обязательно для камеры) |
| **Камера OV2640** | 2MP, JPEG | Источник видеопотока |

**Важно:** для работы камеры нужна **PSRAM**. Обычный ESP32 без PSRAM не потянет.

## 🚀 Установка и прошивка
1. Установи **Arduino IDE** (или PlatformIO).
2. Установи плату **ESP32 by Espressif Systems** в менеджере плат.
3. Выбери плату: **ESP32S3 Dev Module**.
4. В настройках платы обязательно включи:
   - **PSRAM: OPI PSRAM**
   - **Flash Size: 16MB**
   - **Partition Scheme: Huge APP (3MB No OTA/1MB SPIFFS)**
5. В коде замени `ssid` и `password` на свои:
   ```cpp
   const char* ssid = "ТвойWiFi";
   const char* password = "ТвойПароль";
   Прошей ESP32-S3.

Открой Монитор порта (скорость 115200) — там будет IP-адрес.

Открой этот IP в браузере — увидишь видеопоток.

⚠️ Грабли
Без PSRAM не заработает. Если ESP32 без PSRAM — камера выдаст ошибку инициализации.

Питание. ESP32-S3 с камерой жрёт много. Если поток рвётся — проверь блок питания (нужно стабильные 5V и 1A+).

Пины. Распиновка подходит для стандартных плат ESP32-S3 N16R8 CAM (обычно на них написано «ESP32-S3-WROOM-1»). Если у тебя другая плата — сверь пины.

Wi-Fi 2.4 ГГц. ESP32 не поддерживает 5 ГГц. Если роутер раздаёт только 5 ГГц — ничего не заработает.

Нагрузка на сеть. VGA-поток жрёт около 1–2 Мбит/с. Для нескольких камер одновременно нужен нормальный роутер.

🏠 Интеграция с Home Assistant
В HA можно добавить как Generic Camera:

Still Image URL: http://<ip_esp32>/

Stream Source: http://<ip_esp32>/
(Но имей в виду, что MJPEG-поток будет работать только в браузере, для записи в HA лучше использовать Frigate или go2rtc).
